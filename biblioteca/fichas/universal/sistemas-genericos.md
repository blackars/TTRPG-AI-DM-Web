# Sistemas genéricos

> **Género:** Universal · **Tipo:** Colección  
> **Tags:** universal, generico, gurps, fate, savage-worlds, cypher, brp

> **Colección:** agrupa varios motores. Si uno se vuelve central en tu campaña, crea una ficha propia con `plantilla-ficha.md`.

| Sistema | Motor | Dados | Qué aporta | Uso |
|---|---|---|---|---|
| **GURPS** | 3d6 por debajo de habilidad | 3d6 | Simulación detallada, ventajas/desventajas, mundos muy configurables | Campañas realistas o de nicho |
| **Fate Core / Accelerated** | Dados Fudge + aspectos | 4dF | Narrativa compartida, aspectos, puntos de destino | Partidas rápidas y universales |
| **Savage Worlds** | Dados de rasgo + comodín | d4–d12 | Acción pulp, combate rápido, minis opcionales | One-shots y campañas de acción |
| **Cypher System** | d20 + niveles de dificultad | d20 | Descubrimiento, recursos, GM intrusions | Aventura y exploración |
| **BRP** | d100 por debajo de habilidad | d100 | Base porcentual, combate peligroso, magia opcional | Terror, histórico, investigación |

## Cómo elegir

- **GURPS** si quieres detalle y coherencia física; prepárate para configurar.
- **Fate** si la mesa quiere narrar y compartir la autoridad creativa.
- **Savage Worlds** si buscas acción rápida con dados crecientes.
- **Cypher** si quieres un d20 ligero con recursos narrativos.
- **BRP** si vienes de La Llamada de Cthulhu y quieres el mismo esqueleto para otro género.

## Para qué sirve al DM IA

- **Sistema puente:** permite jugar una idea propia sin inventar un motor desde cero.
- **Conversión:** si una ficha no existe, el DM puede proponer una aproximación con estos motores.
- **Transparencia:** la ficha activa y la personalización del usuario tienen prioridad sobre esta tabla.
